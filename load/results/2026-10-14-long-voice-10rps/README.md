# Длинные голоса: CMP → AI, 10 RPS, 14 октября 2026

DEV, версия `dab3578`. Генератор k6 2.3.0 подавал 600 новых запросов в минуту в течение 1 минуты через публичный HTTPS CMP. Использовались только два настоящих OGG/Opus клипа LibriSpeech: 16,267 и 23,267 с, попеременно. Путь запроса: закрытый тестовый маршрут CMP → `SessionClipQueue` → AI с реальными STT/LLM/TTS → загрузка аудиоответа. Telegram webhook и доставка ответа пользователю в тест не входят.

| Показатель | Результат |
| --- | ---: |
| Итерации k6 | 601 |
| Успешно обработанные клипы | 599 |
| Ошибки | 2 создания сессии, `unexpected EOF`, HTTP-статуса нет |
| Пропущенные итерации | 0 |
| Время ответа клипа p50 / p95 / p99 / max | 12,63 / 22,93 / 28,64 / 33,28 с |
| Время AI job p50 / p95 / p99 / max | 8,63 / 11,81 / 14,88 / 16,43 с |
| p95 STT / reply LLM / TTS внутри AI | 1,91 / 4,62 / 5,96 с |
| p95 `HttpClipClient.process` в CMP | 15,42 с |
| Пик активных k6 VU | 172 из 500 выделенных |
| Баланс ключа OpenRouter до / после | $9,37 / $4,21 |

Все 599 запросов, дошедших до клипа, успешно завершились в AI; за период было по 599 HTTP 200 от STT и TTS, 599 завершённых AI job и ни одной ошибки клипа в логах CMP/AI. Оба сбоя были на предыдущем шаге: k6 получил `unexpected EOF` при `POST /internal/load-test/sessions` для двух VU около 09:40:10 MSK. Причина разрыва соединения не установлена. Из-за двух сбоев порог `clip_failed == 0` не пройден, код выхода k6 — 99. Следовательно, этот прогон **не подтверждает безошибочную работу при 10 RPS**.

Время ответа существенно выше короткого контрольного прогона (p95 6,51 с). p95 AI job составил 11,81 с, p95 клиентского ожидания — 22,93 с. Разница включает ожидание и обработку в CMP, а также сеть; индивидуальные пары измерений между k6 и CMP не сопоставлены, поэтому точное место оставшейся задержки этим прогоном не установлено. AI job, начатые в первые 20 с, имели p95 10,05 с; начатые после 60-й секунды — 14,91 с (101 запрос). Одна минута также не доказывает долговременную устойчивость.

После теста исходный `.env` DEV CMP восстановлен, контейнер перезапущен: `/health` вернул 200, тестовый маршрут — 404. Значения токена в результатах нет.

Файлы: [`summary.json`](summary.json) — метрики k6, [`k6.log`](k6.log) — полный вывод, [`ai-timings.log`](ai-timings.log) и [`cmp-timings.log`](cmp-timings.log) — отфильтрованные тайминги, [`long-manifest.json`](long-manifest.json) — входные клипы.
