# System map (code on this branch)

Repo: Kotlin Multiplatform under `cmp/` plus Python `ai-service/` plus `infra/`.

## Components

1. **telegram-service** (`cmp/telegram-service`) — production Telegram bot. HTTPS webhook when `TELEGRAM_WEBHOOK_URL` is set; otherwise HTTP for health only (no bot, no clip proxy).
2. **cmp-service** (`cmp/cmp-service`) — app API for the CMP clients. HTTPS when TLS PEM files exist; otherwise HTTP. No Telegram routes.
3. **ai-service** (`ai-service/`) — FastAPI factory `app.main:create_app`. Real STT→LLM→TTS. Published host port is `AI_SERVICE_PORT` (default 8090).
4. **Redis** — dialogue history when `REDIS_URL` is set. Default TTL **2592000** s (30 days). Key `session:{sessionId}`.
5. **CMP clients** (`cmp/app`) — talk to **cmp-service** over HTTPS. They do **not** call the clip API. Shared TLS/health/AI client code is `cmp/service-common`.

## Process modes

**telegram-service** `Application.kt`:

- `usesWebhook` = `TELEGRAM_WEBHOOK_URL` non-blank.
- Webhook mode: Netty **SSL** connector on `SERVER_PORT`, PEM cert/key, registers Telegram webhook with cert upload, reminder loop in the webhook scope.
- Token without webhook URL is rejected at config init.
- `module()` (tests / non-webhook): `/telegram/webhook` if webhook configured returns **403** bad secret, **503** if secret matches (handlers live only in `startWebhookServer`).

**cmp-service** `Application.kt`:

- TLS when both PEM files exist. With `JWT_SECRET` set, production then requires `DATABASE_URL`.
- Without PEM files: plain HTTP (local `run` and tests).
- No `/telegram/webhook` and no `/admin/metrics`.

Default `AI_SERVICE_BASE_URL` = `http://127.0.0.1:8090`. Default TLS paths: `/opt/telegram-service/tls.crt` and `/opt/cmp-service/tls.crt` (and matching `tls.key`).

HTTP always: `GET /` (template `sayHello("Ktor")`), `GET /health` → `ok`. No Swagger, no public clip proxy.

## Per-session clip queue

`SessionClipQueue`: one processing loop per `sessionId`, `maxQueuedPerUser = 3` (queued + processing). Extra voices → `QueueFull`. If a clip waits behind another, Telegram gets `QUEUED_TEXT` then later the reply.

`HttpClipClient`: poll `300ms`, timeout **90s**. Submit expects HTTP **202**.

## ai-service pipeline

`ClipPipeline.run`: STT → if empty/`no_speech` → TTS clarify (no LLM, empty notes) → else parallel `complete_reply` + `complete_notes`, then `record_turn` (spoken reply only) + TTS.

Clarify string: `I didn't catch that. Could you say it again?` (`pipeline.py`).

Jobs: in-process `JobStore`, TTL `JOB_TTL_SECONDS` default **600**. Pipeline timeout default **60s**.

Greeting: JSON `GREETING_TEXT` vs spoken `GREETING_VOICE_TEXT` (`sessions.py`) — they differ on purpose.

## Skills / Gradle

CMP skills live in `.agents/skills/`. Detekt: `cmp/config/detekt.yml`, CI `./gradlew detekt` from `cmp/`.
