# System map (code on this branch)

Repo: Kotlin Multiplatform under `cmp/` plus Python `ai-service/` plus `infra/`.

## Components

1. **Ktor server** (`cmp/server`) — production Telegram bot. HTTPS webhook when `TELEGRAM_WEBHOOK_URL` is set; otherwise HTTP for health/Swagger/clip **proxy** only (no bot).
2. **ai-service** (`ai-service/`) — FastAPI factory `app.main:create_app`. Real STT→LLM→TTS. Host compose port **8091** maps to container 8090.
3. **ai-service-stub** (`infra/ai-service-stub/`) — echo/mock clips for local Ktor without API keys. Host **8090**. Stub does **not** accept `sessionId` in POST /sessions JSON and returns random note **strings**, not `wrong|||better`.
4. **Redis** — dialogue history when `REDIS_URL` is set. Default TTL **2592000** s (30 days). Key `session:{sessionId}`.
5. **CMP clients** (`cmp/app`) — Android / iOS / Desktop still call template `App()`. Desktop window title is `"cmp"`. They do **not** call the clip API.

## Ktor process modes (`Application.kt` + `AppConfig.kt`)

- `usesWebhook` = `TELEGRAM_WEBHOOK_URL` non-blank.
- Webhook mode: Netty **SSL** connector on `SERVER_PORT` (VPS deploy writes `443`), PEM cert/key, registers Telegram webhook with cert upload, 4-thread webhook scope.
- Token without webhook URL is rejected at config init.
- Default `AI_SERVICE_BASE_URL` = `http://127.0.0.1:8090`.
- Default TLS paths: `/opt/speaking-coach/tls.crt`, `tls.key`.
- `module()` (tests / non-webhook): `/telegram/webhook` if webhook configured returns **403** bad secret, **503** if secret matches (handlers live only in `startWebhookServer`).

HTTP always: `GET /` (template `sayHello("Ktor")`), `GET /health` → `ok`, Swagger `/swagger`, OpenAPI clip routes that **proxy** to ai-service (`AiServiceRoutes.kt`).

## Per-session clip queue

`SessionClipQueue`: one processing loop per `sessionId`, `maxQueuedPerUser = 3` (queued + processing). Extra voices → `QueueFull`. If a clip waits behind another, Telegram gets `QUEUED_TEXT` then later the reply.

`HttpClipClient`: poll `300ms`, timeout **90s**. Submit expects HTTP **202**.

## ai-service pipeline

`ClipPipeline.run`: STT → if empty/`no_speech` → TTS clarify (no LLM, empty notes) → else parallel `complete_reply` + `complete_correction`, `notes_from_rewrite`, then `record_turn` (spoken reply only) + TTS.

Clarify string: `I didn't catch that. Could you say it again?` (`pipeline.py`).

Jobs: in-process `JobStore`, TTL `JOB_TTL_SECONDS` default **600**. Pipeline timeout default **60s**.

Greeting: JSON `GREETING_TEXT` vs spoken `GREETING_VOICE_TEXT` (`sessions.py`) — they differ on purpose.

## Skills / Gradle

CMP skills live in `.agents/skills/`. Detekt: `cmp/config/detekt.yml`, CI `./gradlew detekt` from `cmp/`.
