# Стоимость дня в голосовом цикле

Оценка одного дня одного человека: онбординг или один практический звонок на 5, 10 или 15 минут. Это не шаблон «5 картинок и 20 сообщений» и не сумма всего продакшена за сутки.

Цифры собраны 11 октября 2026. Нагрузка k6 в эти дни не писалась: заголовок тестовой сессии в работающий деплой ещё не выкатывался, так что средние ниже — живые пользователи Telegram.

## Откуда цена

Формула экрана мониторинга — константы `ai-service/app/metrics.py`:

| Статья | Константа | Значение |
| --- | --- | --- |
| Вход LLM | `LLM_PROMPT_USD_PER_MILLION` | $0.20 / 1 млн токенов |
| Выход LLM | `LLM_COMPLETION_USD_PER_MILLION` | $1.20 / 1 млн токенов |
| STT | `STT_USD_PER_HOUR` | $0.111 / час аудио |
| TTS | `TTS_USD_PER_MILLION_CHARS` | $0.62 / 1 млн символов |
| Рубли | `RUB_PER_USD` | 90 |

Комментарий у TTS-константы — `hexgrad/kokoro-82m`. На DEV и PROD в этот день стоит `TTS_PROVIDER=openrouter` и `TTS_MODEL=x-ai/grok-voice-tts-1.0` (на PROD провайдер не задан в файле и берётся дефолт `openrouter`). В Redis `metrics:v2` за 6–10 октября поле cost у TTS и STT равно 0: провайдер не отдал `usage.cost`, и рублёвая строка TTS на экране считается только по константе kokoro. Ниже TTS поэтому тоже по этой константе, а не по счёту Grok.

Вторая колонка для LLM — сумма `usage.cost` из `metrics:v2:day:*:telegram` за 6–10 октября 2026 на PROD (только агрегаты, без идентификаторов чатов). DEV за те же дни слишком мал (1–2 человека), для среднего не брался. Ключи не переписывались.

## Что входит в день

Звонок после онбординга идёт через `ClipPipeline`. На живом процессе в пайплайн подмешана персонализация (`onboarding.py` пишет `pipeline.personalization`). Один успешный голосовой ход:

1. Groq STT, `whisper-large-v3`, один запрос.
2. OpenRouter чат ответа, `openai/gpt-5.6-luna` (`LLM_MODEL`).
3. OpenRouter чат заметок, та же модель (`NOTES_MODEL`), дедлайн `NOTES_TIMEOUT_SECONDS = 10` секунд.
4. Ещё один OpenRouter чат: память человека, `complete_json`, purpose `onboarding`.
5. OpenRouter TTS, `x-ai/grok-voice-tts-1.0`.

Отдельно от клипов, один раз на звонок: вопрос на старте (чат + TTS, без STT) и текстовый разбор в конце (один чат, без STT и TTS).

Онбординг копится до `SPEECH_LIMIT_SECONDS = 120` распознанных секунд. На каждый голосовой ответ: STT, оценка (`assess`), заметки, TTS следующего вопроса. На последнем ответе вместо вопроса — голос закрытия. Плюс один TTS вступления (в процессе он кэшируется по скорости, в смету одного человека заложен один раз). В конце ещё четыре чата без нового аудио: callback закрытия, проверка примеров, текст разбора, запись памяти.

Повтор провайдера после 429 в смету не входит. Один такой повтор удваивает расход квоты этого вызова. Уточнение «не расслышал» дешевле: STT и короткий TTS, без чатов.

## Средний ход на проде

`metrics:day:*` за 6–10 октября 2026, Telegram:

- 359 ходов, 8 491 731 мс STT → **23.7 с** на ход.
- 92 713 символов TTS → **258 символов** на ход.

Токены и `usage.cost` из `metrics:v2` за те же дни:

| Назначение | Вызовов | Вход / вызов | Выход / вызов | Прайс по константам | `usage.cost` |
| --- | ---: | ---: | ---: | ---: | ---: |
| reply | 206 | 2 276 | 138 | $0.000621 | $0.000726 |
| notes | 358 | 1 688 | 72 | $0.000423 | $0.000159 |
| onboarding | 419 | 916 | 258 | $0.000493 | $0.000501 |

Заметки в `usage.cost` примерно в 2.7 раза дешевле константы. Ответ чуть дороже константы. Онбординг-чат совпадает с константой. В бакете onboarding смешаны оценка, память, старт звонка и разбор; отдельного ключа на память нет. Для третьего чата хода и для чатов старта/разбора взято это среднее. Для памяти это верхняя оценка.

STT одного хода по константе: 23.7 / 3600 × 0.111 = **$0.000729**. TTS: 258 / 1e6 × 0.62 = **$0.000160**.

## Смета одного дня

Число ходов — сколько клипов по 23.7 с нужно, чтобы добрать цель, с округлением вверх (последний клип может перешагнуть цель).

| День | Состав | Прайс констант | LLM по `usage.cost`, STT/TTS по константам |
| --- | --- | ---: | ---: |
| Онбординг | 5 голосовых ответов (120 с) + TTS вступления + 4 чата закрытия | $0.011 / 1.00 ₽ | $0.010 / 0.89 ₽ |
| Звонок 5 мин | 13 ходов + старт + разбор | $0.033 / 2.94 ₽ | $0.031 / 2.77 ₽ |
| Звонок 10 мин | 26 ходов + старт + разбор | $0.064 / 5.78 ₽ | $0.060 / 5.43 ₽ |
| Звонок 15 мин | 39 ходов + старт + разбор | $0.096 / 8.62 ₽ | $0.090 / 8.09 ₽ |

Один ход звонка по константам: reply + notes + onboarding-чат + STT + TTS = **$0.00243 / 0.22 ₽**.

Повтор assessment при лимите токенов, повтор 429 и путь «не расслышал» в таблицу не сложены. Курс 90 ₽ за доллар фиксированный, как на экране, без запроса курса.

Публичная цена живой TTS-модели `x-ai/grok-voice-tts-1.0` на OpenRouter — $15 за миллион символов (страница модели, 11 октября 2026). Это не константа экрана. На 258 символов ход стоит $0.00387 вместо $0.00016. Если заменить только TTS, день становится примерно таким: онбординг $0.034 / 3.0 ₽, звонок 5 минут $0.085 / 7.6 ₽, 10 минут $0.165 / 14.8 ₽, 15 минут $0.244 / 22.0 ₽. Экран мониторинга эти рубли не показывает, пока константа остаётся ценой kokoro.
