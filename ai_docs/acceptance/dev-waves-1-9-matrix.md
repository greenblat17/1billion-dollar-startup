## Запуск и границы

1. Сверить release SHA Ktor, AI и Mini App, миграции, health, CMP→AI auth, Foundation context и `AGENT_TEST_ENABLED=true` в DEV. Readiness не доказывает диалог.
2. Через SSH вызвать `/internal/agent-test/v1/{uuid}` по loopback с токеном из DEV env; не публиковать маршрут. Один ход — один платный вызов. Сохранить закрытые JSON и читаемый Markdown transcript. Для дальнейших ходов использовать тот же UUID. После HTTP 402 остановиться.
3. Текстовый адаптер проверяет только FoundationTutor/native tools/PostgreSQL. `/start`, Telegram webhook/доставка, Trial, Voice/Realtime, Mini App audio/S3 и живое восприятие требуют отдельных тестовых аккаунтов и интерфейсов.
4. До отдельной живой проверки каждая строка имеет `blocked`, даже если Notion уже содержит галочку кодовой проверки. В отчёте по каждому AC указывать ссылку на transcript и точное ограничение доказательства.
