# Run locally, env, CI

## Env (names only)

From `.env.example` and `Settings.from_env` / `AppConfig.fromEnv`:

| Name | Role |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | Required for webhook server |
| `TELEGRAM_WEBHOOK_URL` | Enables TLS webhook mode |
| `TELEGRAM_WEBHOOK_SECRET` | Header + `setWebhook` secret |
| `AI_SERVICE_BASE_URL` | Ktor → Python |
| `AI_INTERNAL_TOKEN` | Shared header `X-Internal-Token` on `/v1/*` and `/internal/*`; required to start webhook |
| `JWT_SECRET` | HMAC for app Bearer; if unset, Ktor does not install `/v1/auth` and session routes |
| `DATABASE_URL` | Postgres JDBC URL for app users/sessions; required with `JWT_SECRET` in webhook mode |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | Create-if-missing Postgres on the Ktor host (`127.0.0.1:5432`). Skip container if `POSTGRES_PASSWORD` unset |
| `OPENAI_REALTIME_API_KEY` | platform.openai.com key for mint+SDP; ai-service only |
| `SPEAKING_COACH_API_BASE_URL` | CMP client Ktor base. Local: env or `cmp/client.local.properties` `speakingCoach.apiBaseUrl`. CI packages bake `https://$DEV_CMP_SERVER_HOST` (`PROD_CMP_SERVER_HOST` on `main`). Not a key inside the `.env` blob. |
| `SERVER_PORT` | Default 8080; VPS 443 |
| `TLS_CERT_PATH` / `TLS_KEY_PATH` | PEM for webhook TLS |
| `GROQ_API_KEY` / `GROQ_BASE_URL` | STT, default Groq OpenAI-compat URL |
| `OPENAI_API_KEY` / `OPENAI_BASE_URL` | LLM+TTS (OpenRouter by default) |
| `STT_MODEL` | default `whisper-large-v3` |
| `LLM_MODEL` | default `openai/gpt-4o-mini` |
| `TTS_MODEL` / `TTS_VOICE` / `TTS_RESPONSE_FORMAT` | default `hexgrad/kokoro-82m`, `af_heart`, `mp3` then ffmpeg→OGG |
| `FFMPEG_BIN` | default `ffmpeg` |
| `REDIS_URL` | dialogue; unset = memory |
| `DIALOGUE_TTL_SECONDS` / `DIALOGUE_MAX_MESSAGES` | 2592000 / 40 |
| `JOB_TTL_SECONDS` / `PIPELINE_TIMEOUT_SECONDS` | 600 / 60 |
| `LOG_LEVEL` | default INFO |
| `METRICS_PASSWORD` | Ktor page `/admin/metrics`. Repository secret of that name. Deploy writes it into the CMP server env. Empty disables the page. Not part of the AI env blob. |

Counters start at deploy. They are Redis keys `metrics:*` on the AI host and do not use the dialogue TTL. Old `session:*` history is not backfilled. Ruble rates are constants in `ai-service/app/metrics.py`: public USD list price times `RUB_PER_USD`, not env.

The same page shows the Telegram funnel for the last 14 Moscow days. Start is the first `/start`. Activated is the first voice, even if the reply fails. Engaged is the third finished clip, including the clarify line. Returned counts a later calendar day when the person sends `/start` or a voice again; the same person can count on more than one day. A `?start=` payload of 1–64 letters, digits, `_`, or `-` is stored once and is not replaced. An empty `/start` stays `direct` until a real payload arrives.

The chat table shows `@username · first last` from the private Telegram chat, or `—` when neither exists. Ktor sends `username` (without `@`) and `name` with every `/internal/funnel/start` and `/internal/funnel/voice`; ai-service stores the latest values in `metrics:chat:{sessionId}` next to `turns`. A chat appears only after its first finished turn, and its name fills in on the next `/start` or voice after deploy.

Daily reminder (plan: `plans/2026-09-26-daily-reminder.md`). `POST /internal/reminders/claim` (needs `X-Internal-Token`, no body) returns `{"targets":[{"sessionId":"tg-123","name":"Alex Green"|null}]}`. Targets are every Telegram session, `tg-<number>` or the live form `tg-ChatId(chatId=<number>)` (Ktor stringifies the tgbotapi `ChatId`), from `metrics:funnel:user:*` and `metrics:chats`, minus today's Moscow `metrics:dau:{day}`. Each returned session is marked with `reminder:sent:{day}:{sessionId}` (`SET NX`, TTL 2 days), so a second call on the same Moscow day returns only sessions not yet claimed. Ktor calls it once per day in the 19:00–21:00 Moscow window (webhook mode only) and sends one English text per target. A manual run from the dashboard uses the same claim.

`POST /internal/reminders/report` (token, JSON) body: `{"mode":"auto"|"manual","startedAt":"ISO","finishedAt":"ISO","claimed":N,"results":[{"sessionId":"tg-1","templateId":"day_went","status":"sent"|"blocked"|"failed"}]}`. Unknown modes become `auto`, unknown statuses `failed`, template ids outside `[a-z0-9_]{1,64}` become `unknown`. ai-service stores `reminder:day:{day}`, `reminder:tpl:{id}` + `reminder:templates`, `reminder:last:{session}`, `reminder:ignored:{session}`, `reminder:reply_seconds:{day}` (last 1000), `reminder:runs` (last 30). `/internal/funnel/voice` counts a reply when it lands within 24 hours of the last sent reminder.

`GET /internal/metrics` adds `reminders: {today, week, days[14], segments[new|active, 7 days], templates, replyMedianSeconds|null, runs, autoToday|null, forecast}` and, in each `chats` row, `lastReminderAt` (ISO or null) and `reminderIgnored`. Ktor DTO fields default, so an older ai-service without the block still renders.

Ktor webhook TLS keystore password in code is the literal `"ktor"` (not a user secret).

## Local commands

Gradle (from `cmp/`, `GRADLE_USER_HOME=$HOME/.gradle`):

```bash
export GRADLE_USER_HOME="$HOME/.gradle"
cd cmp
# Client API URL: copy client.local.properties.example → client.local.properties
./gradlew :server:test
./gradlew :server:run          # HTTP, no Telegram unless webhook env set
./gradlew detekt
./gradlew :app:desktopApp:run
./gradlew :app:androidApp:assembleDebug
```

Python:

```bash
cd ai-service
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt
export GROQ_API_KEY=... OPENAI_API_KEY=...
uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8090
pytest
```

Unit tests stay local (`:server:test`, `pytest`). Integration against the real stack is Redeploy to DEV hosts, not Docker Compose / `ai-service-stub`.

`:server:run` is HTTP without Telegram unless webhook env is set. Point it at DEV FastAPI only if you intend to hit that host.

Telegram **cannot** use local HTTP polling; webhook needs public HTTPS + cert.

## CI

- `.github/workflows/cmp.yml` — detekt, Android/Desktop/iOS packages, `:server:test` + `buildFatJar`. **Деплоя нет.** Client packages bake `SPEAKING_COACH_API_BASE_URL=https://$DEV_CMP_SERVER_HOST` (PRs/feature; `PROD_CMP_SERVER_HOST` on `main`). Tests do not need the URL.
- `.github/workflows/ai-service.yml` — pytest, upload app. **Деплоя нет.** Redis не трогает.
- `.github/workflows/redeploy.yml` — **Redeploy DEV** (`workflow_dispatch`, `DEV_*`). Галки `cmp-server` / `ai-server` (обе default on). Выключенная — job skipped, workflow зелёный.
- `.github/workflows/redeploy-prod.yml` — **Redeploy PROD**, те же галки, secrets `PROD_*`. Ветка не выбирает хост: с `main` и с PR запуск одинаковый. Deployments: environment `deploy-dev` / `deploy-prod`, без approve. Concurrency на хост (`ktor-prod` / `ktor-dev` / `ai-prod` / `ai-dev`), `cancel-in-progress: false`.
- `.github/actions/setup-cmp` — Zulu JDK 21, Gradle cache.

Python 3.12. Dockerfiles install ffmpeg in ai-service image.

## STT / TTS implementation notes

- STT: Groq `verbose_json` + word timestamps; `no_speech` if empty text or `no_speech_prob >= 0.8`; retry via wav 16 kHz (`stt.py`, `audio.py`).
- TTS: OpenRouter/OpenAI speech API; `instructions` only if model starts with `openai/`; then `to_ogg_opus`.
- Retry helper: `app/retry.py` `once_on_retryable`.
